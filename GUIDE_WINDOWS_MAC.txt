ORIGIN EXTRACT 2.1.2
Created by Amir MEDDAS

INSTALL
Windows: run OriginExtract-2.1.2-Windows-x64-Setup.exe.
Mac Apple Silicon: open the arm64 DMG and drag Origin Extract to Applications.
Mac Intel: use the x86_64 DMG. Requires macOS 12 or later.
Python and dependencies are bundled with these distributions.
The builds are unsigned and not notarized. A provenance warning or execution
block is possible. Author metadata is not a verified digital signature.

EXPORT
Open a project, select sheets and click Export.
Use TXT / TAB to set TXT/CSV, separator, headers and decimal notation.
Destination chooses the output folder. Every export creates a new folder;
existing exports are never overwritten.
Preview values may be shortened. Hover for full values; exports preserve
full precision. Search filters the list without deselecting hidden sheets.
Plots are previews and may be sampled. No fitting is applied.

MAC OFFLINE
An .originpack contains tables, metadata and integrity hashes.
It opens and re-exports without Origin Viewer or a connected PC.
Create it on Windows: open the project, then ... > Share .originpack.
Transfer the resulting file to your Mac.

NEW .OPJU FROM MAC
Raw .opju files are converted on a Windows PC with Origin Viewer.
PC: ... > Mac / PC > My Windows PC > Start relay on this PC.
Copy one PC address and the connection key shown below it.
Mac: ... > Mac / PC > My Mac. Paste the address and key, then Test connection
and Save. Open the .opju on the Mac; the PC converts it and returns the tables.
Keep the PC on, its session open, and the relay running.

BROWSER TEST
Opening the PC address in a browser shows "Relay is running" with instructions.
The browser sends no connection key. This page only confirms that the relay
is reachable from that device. A test on the PC does not prove the Mac can
reach it. Use Test connection in the Mac app to verify the address AND key.
Protected requests distinguish "Connection key required" from "Incorrect
connection key". Copy the current key from the PC if the Mac reports an error.

WINDOWS PERMISSION WAS DENIED
PC: ... > Mac / PC > My Windows PC > Firewall.
In Windows Firewall, choose Change settings and allow OriginExtract.exe on
Private networks. Source launchers use pythonw.exe or python.exe instead.
Windows can retain a blocking rule after a denied request without asking
again. Check again only reads the rules; it does not change permissions.
Use a trusted private network or Tailscale. Public university networks may
isolate devices even when the firewall allows the program.

The relay uses HTTP and an access key on TCP port 8765. It starts manually
and does not modify the firewall. It is not an encrypted Internet service.
No cloud service receives your projects. While converting, avoid interacting
with Origin Viewer or copying text: the converter uses the PC clipboard.
The initial text is restored when possible; other clipboard formats are not.
Concurrent conversions wait for each other to avoid clipboard conflicts.

COLUMN NAMES AND EXCLUSIONS
Original names, units and scientific text retain their original language.
Confirmed name mappings are marked Restored and only apply to the exact
source project. A column letter indicates an unknown name.
If metadata cannot be read, column letters are kept and a warning is recorded.
Graphs, embedded graph sheets, analysis reports, layouts and matrices are
not exported as data tables. Exclusions appear in _rapport.json.
Complex FFT values keep their full precision. Viewer restrictions still apply.
The source project is unchanged. On conversion failure, the error message
points to a local log under AppData/Local/OriginExtract/Logs on Windows.
