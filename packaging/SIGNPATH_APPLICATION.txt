Description:
Origin Extract is a scientific desktop utility for exporting Origin worksheet
tables to TXT/CSV in batches. Windows conversion automates a separately installed
Origin Viewer. Cross-platform .originpack files let macOS users work offline;
an optional user-started relay can convert selected OPJU projects on a Windows PC.
The UI is English and credits Amir MEDDAS. Python, PySide6/Qt, pywinauto and pywin32
are bundled or used under their respective open-source licenses. Origin Viewer
is proprietary and is NOT bundled with our distributions.

Signing need:
Our unsigned Windows installer is blocked by a code-integrity policy when Inno
Setup launches an unsigned temporary helper. We seek signing for our own Windows
application, installer, temporary setup helper and uninstaller. We understand
that signing only the outer Setup.exe is insufficient and that upstream third-
party libraries must not be signed with our project certificate.
Please advise on the supported multi-stage artifact configuration for Inno Setup.
